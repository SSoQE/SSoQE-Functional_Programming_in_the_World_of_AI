# Package logos and badges

## `testthat.svg`

Official `{testthat}` hex sticker downloaded on 6 September 2026 from the
[RStudio hex-stickers repository](https://github.com/rstudio/hex-stickers/blob/main/SVG/testthat.svg).
That repository releases all stickers under
[CC0](https://github.com/rstudio/hex-stickers/blob/main/LICENSE.md).

The logo links to the [`{testthat}` documentation](https://testthat.r-lib.org/)
in the presentation.

## `assertthat-course-hex.svg`

The `{assertthat}` project does not publish a package hex sticker, and no
`assertthat` sticker was present in either the official RStudio hex-stickers
repository or the community hexbin archive when checked on 6 September 2026.
This is therefore an SSoQE course badge, not an official `{assertthat}` logo.

The badge uses the SSoQE colour tokens and a boundary-check motif. It was
created specifically for this lesson and is distributed under the repository's
MIT License. It links to the
[`assert_that()` documentation](https://search.r-project.org/CRAN/refmans/assertthat/html/assert_that.html)
in the presentation.
