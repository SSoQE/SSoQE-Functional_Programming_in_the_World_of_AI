# Original lesson illustrations

These illustrations were generated specifically for the 2026 SSoQE lesson on
5 September 2026 using OpenAI's built-in image-generation tool. They replace
the unlicensed Reddit meme formerly used in the SPROuT presentation.

## Reuse

No third-party source images or existing meme templates were used. These two
project-generated assets are distributed with this repository under the terms
of its MIT License.

## `functional_revelation.png`

Purpose: restore the humorous moment in which participants realise that a
function can be passed to another function.

Prompt summary: an ecology researcher at a laptop has a delighted coding
realisation, surrounded by abstract nested-function shapes. Contemporary
editorial-cartoon style, SSoQE palette, no text, logos, copyrighted characters,
or existing meme-template likenesses.

## `assertion_gatekeeper.png`

Purpose: make runtime assertions memorable as a function's boundary check.

Prompt summary: a friendly but serious gatekeeper at a function-shaped doorway
allows orderly valid inputs through while rejecting several chaotic unsupported
inputs. Contemporary editorial-cartoon style, SSoQE palette, no text, logos,
code, or copyrighted characters.
