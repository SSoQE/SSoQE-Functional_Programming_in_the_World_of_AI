# Third-party visual assets

This file records every third-party visual used in the 2026 SSoQE lesson.
Slide-level source notes, visible captions, and accessible alternative text are
also included in `Presentation/presentation.qmd`.

## `Figures/xkcd-automation.png`

- Work: [xkcd #1319, "Automation"](https://xkcd.com/1319/)
- Creator: Randall Munroe
- Licence: [Creative Commons Attribution-NonCommercial 2.5](https://xkcd.com/license.html)
- Teaching purpose: a humorous opening prompt about how automation shifts work
  toward debugging, specification, and maintenance.

## `Figures/advanced-r-fp.png`

- Work: functional-programming input/output matrix from
  [Advanced R, 2nd edition, Functional programming](https://adv-r.hadley.nz/fp.html)
- Author: Hadley Wickham
- Licence: [Creative Commons Attribution-NonCommercial-ShareAlike 4.0](https://adv-r.hadley.nz/)
- Teaching purpose: distinguish the four combinations of data and function inputs.

## `Figures/advanced-r-map.png`

- Work: the `map()` diagram from
  [Advanced R, 2nd edition, Functionals](https://adv-r.hadley.nz/functionals.html)
- Author: Hadley Wickham
- Licence: [Creative Commons Attribution-NonCommercial-ShareAlike 4.0](https://adv-r.hadley.nz/)
- Teaching purpose: show one stable function receiving each element of an input
  collection and producing one corresponding output element.

## `Figures/advanced-r-map-list.png`

- Work: the list-mapping diagram from
  [Advanced R, 2nd edition, Functionals](https://adv-r.hadley.nz/functionals.html)
- Author: Hadley Wickham
- Licence: [Creative Commons Attribution-NonCommercial-ShareAlike 4.0](https://adv-r.hadley.nz/)
- Teaching purpose: make the list return shape of `purrr::map()` visible.

## `Logos/purrr.png`

- Work: official `{purrr}` hex sticker from the
  [RStudio hex-stickers repository](https://github.com/rstudio/hex-stickers/blob/main/PNG/purrr.png)
- Licence: [CC0](https://github.com/rstudio/hex-stickers/blob/main/LICENSE.md)
- Teaching purpose: introduce the package and link directly to its
  [documentation](https://purrr.tidyverse.org/).
